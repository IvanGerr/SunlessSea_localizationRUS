# SunlessSea_localizationRUS

> [!IMPORTANT]
> **Поддерживается только Sunless Sea: Zubmariner для Epic Games, Windows, версия `2.2.12.202509090925-Windows`.**
> Установщик сверяет SHA-256 изменяемых файлов и отказывается работать с другой сборкой игры.

Неофициальная русская локализация Sunless Sea: Zubmariner, адаптированная для
актуальной Epic-версии игры. Проект объединяет переведённые сюжетные данные,
шрифты и текстуры из более ранних русификаторов с точечными исправлениями
интерфейса текущей версии.

## Состояние

- **Стабильный выпуск:** `v0.1.1`.
- **В разработке:** `v0.1.2` — дополнительные подписи интерфейса и исправления
  формулировок. Манифест и исходники уже находятся в `main`, готовый установщик
  будет выпущен после проверки в игре.
- **Магазин:** Epic Games.
- **Дополнение:** Zubmariner обязательно.

## Установка

1. Скачайте ZIP из раздела
   [Releases](https://github.com/IvanGerr/SunlessSea_localizationRUS/releases).
2. Закройте Sunless Sea.
3. Распакуйте архив и запустите `Install.cmd`.
4. После успешной проверки файлов запустите игру обычным способом.

Для удаления перевода запустите `Uninstall.cmd`. Перед изменением игры
установщик сохраняет резервную копию в
`%LOCALAPPDATA%\SunlessSeaRuInstaller`.

## Что находится в репозитории

- `src/` — утилиты для точечного изменения managed DLL, Unity UI и JSON.
- `manifests/` — проверяемые замены строк и хеши поддерживаемой версии.
- `installer/` — установочные и восстановительные PowerShell-скрипты.
- `scripts/` — проверка публичного дерева и сборка Release-архива.
- `docs/` — совместимость, сборка и правила перевода.

Оригинальные игровые DLL, Unity assets, сохранения и скачанные архивы
руссификаторов в Git не входят. Готовый установщик распространяет двоичные
дельты, которые применяются только к проверенной копии игры.

## Разработка

Требуется .NET SDK 10:

```powershell
dotnet restore .\SunlessSea.Localization.slnx
dotnet build .\SunlessSea.Localization.slnx -c Release
.\scripts\Test-PublicTree.ps1
```

Подробности приведены в [BUILD.md](docs/BUILD.md). Перед любым новым выпуском
обязательно выполняются проверки внутренних UI lookup-строк и реальный запуск
игры.
