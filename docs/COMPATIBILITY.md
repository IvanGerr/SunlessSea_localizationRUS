# Совместимость

## Поддерживаемая игра

| Параметр | Значение |
|---|---|
| Игра | Sunless Sea: Zubmariner |
| Магазин | Epic Games |
| ОС | Windows |
| Версия | `2.2.12.202509090925-Windows` |

Версия в интерфейсе не является достаточной проверкой. Установщик `v0.1.1`
сверяет исходный SHA-256 каждого изменяемого файла:

| Файл | Исходный SHA-256 |
|---|---|
| `resources.assets` | `68B02C9902B27A335221B9D422433E31AAD2415074607C4CB9B1761E57641E75` |
| `resources.assets.resS` | `ABC4AF4ED798B21BEDF479C62F12F188BF87743AB9D1F5EB1837A202895C3EC1` |
| `sharedassets0.assets` | `47069170E5DE96E697B5786992CEA4885126FA30A40ECFD6D224F9544C7568B4` |
| `Managed\Sunless.Game.dll` | `0823BD64B1A3975BF1CFEF87C0808978ACFD0F04B2227C75750D7C90CCB3E790` |
| `Managed\Failbetter.Core.dll` | `66925ED678E8387219E29A85A01BA6980B7C17436DF1DB947EE641AF3A8796ED` |

При несовпадении хотя бы одного хеша установка прекращается до изменения
файлов. Проверка файлов в Epic Games возвращает игру в исходное состояние.

Steam, GOG, версия без Zubmariner и будущие обновления игры не поддерживаются
этим манифестом. Для них требуется отдельная адаптация и отдельный набор хешей.
