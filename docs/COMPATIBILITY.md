# Совместимость

## Поддерживаемая игра

| Параметр | Значение |
|---|---|
| Игра | Sunless Sea: Zubmariner |
| Магазин | Epic Games |
| ОС | Windows |
| Версия | `2.2.12.202509090925-Windows` |

Установщик читает `VersionNumber` из `resources.assets` и сравнивает найденную
версию с указанной в манифесте. Дополнительно сверяется исходный SHA-256 каждого
изменяемого файла:

| Файл | Исходный SHA-256 |
|---|---|
| `resources.assets` | `68B02C9902B27A335221B9D422433E31AAD2415074607C4CB9B1761E57641E75` |
| `resources.assets.resS` | `ABC4AF4ED798B21BEDF479C62F12F188BF87743AB9D1F5EB1837A202895C3EC1` |
| `sharedassets0.assets` | `47069170E5DE96E697B5786992CEA4885126FA30A40ECFD6D224F9544C7568B4` |
| `Managed\Sunless.Game.dll` | `0823BD64B1A3975BF1CFEF87C0808978ACFD0F04B2227C75750D7C90CCB3E790` |
| `Managed\Failbetter.Core.dll` | `66925ED678E8387219E29A85A01BA6980B7C17436DF1DB947EE641AF3A8796ED` |

Стабильный установщик `v0.1.1` прекращает установку при несовпадении хешей.
Начиная с `v0.1.2`, поведение зависит от версии игры:

- если версия совпадает, но хеш отличается, файл считается изменённым или
  повреждённым, и установка прекращается до изменения файлов;
- если версия отличается, установщик предупреждает о риске, показывает обе
  версии и предлагает продолжить экспериментальную установку;
- без явного ответа `ДА` файлы не изменяются;
- после согласия двоичные дельты применяются к непроверенным файлам без гарантии
  итогового хеша. Игра может вылетать или перестать запускаться.

Перед экспериментальной установкой также создаётся полная резервная копия
изменяемых файлов. Проверка файлов в Epic Games возвращает игру в исходное
состояние.

Steam, GOG, версия без Zubmariner и будущие обновления игры не проверены этим
манифестом. Экспериментальный режим позволяет попробовать установку, но не
заменяет отдельную адаптацию и тестирование таких сборок.
