# Правила перевода

## Зафиксированная терминология

| Оригинал | Перевод |
|---|---|
| Log Book | Судовой журнал |
| Combat Item | Снаряжение |
| Zeebat | Зи-бэт |
| Hold | Трюм |
| Overboard | За борт |
| Deck Weapon | Палубное орудие |
| Forward Weapon | Носовое орудие |
| Aft Weapon | Кормовое орудие |
| Fallen London | Падший Лондон |
| Condiments | Вкусовые добавки |

Для `(невнятное бормотание)` сохраняются скобки и не добавляется
восклицательный знак.

## Технические ограничения

В интерфейсе игры одинаковая английская строка может использоваться и как
видимая надпись, и как внутреннее имя Unity-объекта. Глобальная замена таких
строк ломает кнопки и закрытие окон.

Поэтому:

1. Unity-текст меняется по точному `PathId` и ожидаемому исходному значению.
2. Строки DLL меняются только внутри конкретного типа и метода.
3. Для каждой DLL-замены проверяется ожидаемое число совпадений.
4. После патча сравниваются UI и menu lookup-вызовы с чистой DLL.
5. Готовая сборка проверяется реальным запуском игры и соответствующим экраном.

Новые непереведённые надписи следует добавлять отдельными узкими изменениями,
не расширяя уже проверенный патч без необходимости.
